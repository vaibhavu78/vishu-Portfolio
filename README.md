# vishu-Portfolio
A modern personal portfolio website built with Next.js, React, and TypeScript.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- CSS
- JavaScript
- Shadcn UI
- Lucide React
- React Icons
- Vercel Analytics

## Features

- Modern responsive portfolio UI
- Interactive components
- Social media integration
- Image & video sections
- Responsive design
- Modern animations and styling

## Project Structure

- `app/` — Main application pages and layout
- `components/` — Reusable UI components
- `lib/` — Utility functions
- `public/` — Images, videos and other assets
